Installation

  1. Téléchargez le fichier depuis votre téléphone Android, puis ouvrez-le dans vos téléchargements.
  2. Android vous demande si vous acceptez d'installer une application provenant d'une source inconnue. Validez pour continuer.
  3. Lancez FLUX depuis votre écran d'accueil.

Si un message signale une « application non vérifiée », choisissez Installer quand même. FLUX est distribué en dehors du Play Store, Android ne peut donc pas la reconnaître.
